# Support

Kāhea is currently maintained on a best-effort basis.

- Usage questions, reproducible bugs, and feature requests belong in
  [GitHub Issues](https://github.com/copyleftdev/kahea/issues).
- Suspected vulnerabilities belong in
  [private vulnerability reports](https://github.com/copyleftdev/kahea/security/advisories/new).
- Include the Kāhea version, operating system, redacted input format, command, exit code, and the
  smallest output envelope that demonstrates the problem.

Please do not post credentials, private API descriptions, customer responses, or evidence-store
contents in an issue.
